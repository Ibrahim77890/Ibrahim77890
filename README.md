## Featured Projects

A few of my most substantial, production-style projects are below. Smaller experiments and course repos are intentionally left off this page — the full list is on my [portfolio](https://ibrahim-qaiser-667.vercel.app/).

### [CallistoAI](https://github.com/Ibrahim77890/CallistoAI/tree/production) — Agentic Conversational CI/CD Automation Platform
A modular MCP (Model Context Protocol) architecture integrating 48+ tools — Jenkins, Neo4j, Kafka, Redis, GitHub — behind a React front end and Node.js backend, unifying CI/CD orchestration and build automation into a single conversational interface with real-time pipeline visualization.

`Node.js` `React` `Docker` `Jenkins` `Kafka` `Redis` `Neo4j`

### [SmartFlix-IaC](https://github.com/Ibrahim77890/smartflix-iac) — Terraform-Based Streaming Platform Infrastructure on GCP
A Netflix-styled, multi-environment (DEV/STG/UAT/PROD) cloud infrastructure provisioned with Terraform, using GKE Autopilot, Cloud Run, and Pub/Sub for elastic, event-driven scaling, with GitOps-based deployment automation and policy enforcement.

`Terraform` `GCP` `GKE` `GitOps` `Cloud Run` `Pub/Sub`

### [Learners Platform](https://github.com/Ibrahim77890/LearnersPlatform) — Course Management Application (MERN Stack)
A full-stack course platform with authentication, role-based user access, and RESTful APIs powering enrollment, multi-course purchases, and progress tracking.

`MongoDB` `Express` `React` `Node.js`

### [GitCMDB-Bash](https://github.com/Ibrahim77890/GitCMDB) — Git-Backed Configuration Management Database
A lightweight, filesystem-first CMDB written in Bash that stores infrastructure assets as version-controlled JSON, using Git itself as an immutable transaction journal for audit trails and state recovery.

`Bash` `Git` `Systems Design`
